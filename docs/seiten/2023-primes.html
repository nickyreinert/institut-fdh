Primes Web-App

Primes Web App is a JavaScript implementation for visualizing prime numbers on spiral structures. It provides an interactive and dynamic view of mathematical patterns through configurable parameters.

A core feature is extensive parameter control, including spiral scaling, color mapping, and visual presentation options. Many settings are animatable, enabling time-based transformations.

The app supports both exploration and teaching by making prime distribution visible on a non-linear structure.
