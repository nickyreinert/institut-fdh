Privacy Diagnostic Utility

AYA - Are You Anonymous?

This in-browser diagnostic maps which browser and environment signals are observable and how those signals can contribute to fingerprinting.

Keep the retro 90s terminal feeling, but read results like a report: scan categories first, then open cards for details.

How To Read This Report

  • Each category groups related signals (network, browser, device, storage, and behavior).
  • Each card has a current value and a risk tag.
  • Expand cards to view raw details and context notes.
  • Use run to refresh checks that are asynchronous or environment-dependent.

Risk Legend

  • HIGH Strong fingerprinting or leakage surface.
  • MED Potentially identifying, context-dependent.
  • LOW Limited uniqueness by itself.
  • INFO Diagnostic context only.
