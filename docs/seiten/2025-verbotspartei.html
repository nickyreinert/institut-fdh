Verbotspartei

  • Blog post about Verbotspartei
  • Interactive dashboard

A short analysis of election programs from major German parties using multiple AI chatbots.

The starting point is the recurring claim that the party "Bündnis 90/Die Grünen" is a so-called "Verbotspartei".

To test this claim, election programs from 8 parties in recent federal elections were analyzed with different chatbot systems.

The evaluation does not claim scientific perfection, but it provides interesting comparative insights.

The structured outputs are visualized in a dashboard. The following models were used:

  • Deepseek (Thinking mode)
  • Gemini
  • Claude Sonnet 4.5
  • Gemini
  • Grok 4.1
  • Qwen3-Max
  • Mistral
